# Content Machine

Read and follow `AGENTS.md` for shared repository instructions, then load only
the account files and canonical skills needed for the request.

Use `/make-slideshows` to make or continue a batch. Its project skill links to
`references/skills/make-slideshows/SKILL.md`, the same workflow used by Codex.
Account preferences and approval/status records live in `accounts/antigpt/`;
recover them before asking the user to repeat decisions from another session.
