## Use in posts

- Keep these source files here. Use stable media paths in the shared CapCut
  project while editing; after final approval, archive selected clean
  backgrounds in `assets/post-sources/N/` (relative to the account root).
  Finished `01.png`–`05.png` and `reel.mp4` sit directly in the flat post folder.
- Pair the approved avatar selfie hook with three varied study backgrounds
  and the CTA. Default to 9:16, three seconds per slide, and separate purple
  highlighted top/bottom text layers.
- Rotate settings and combinations. For example: café 02 → home desk 04 →
  library 06; or sunset 19 → library 23 → night desk 30.
- Source images are unchanged. Images 05, 07, 13, and 15 include small source
  watermarks; `sources.json` records source links, queries, dimensions and hashes.
- The contact sheets are overviews, not backgrounds. Avatar face-swap
  composition references still belong in `boards/`.
